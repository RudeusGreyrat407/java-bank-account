# ДЗ: банковский счёт (Java)

**Студент:** Яшкин Тимур Сергеевич
**Группа:** 09-411

## Что реализовано
- `Currency` — enum валют с курсом в копейках.
- `Balance` — неизменяемый (`final`) баланс: сумма в копейках + валюта, операции `add`, `subtract`, `convertTo` возвращают новый объект.
- `BankAccount` — счёт с балансом, переводами между счетами, дневным лимитом на списание, заморозкой счёта и историей операций.
- `InsufficientFundsException`, `WithdrawLimitExceededException` — свои исключения.
- `Main` — демонстрация работы и всех корнер кейсов.

## Запуск
```
javac -encoding UTF-8 -d out src/*.java
java -cp out Main
```
